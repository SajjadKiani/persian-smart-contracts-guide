# راهنمای فارسی توسعهٔ قرارداد هوشمند

راهنمایی برای برنامه‌نویسانی که توسعهٔ نرم‌افزار را می‌شناسند و می‌خواهند مدل اجرای قراردادهای هوشمند و مسیر ساخت آن‌ها را یاد بگیرند.

متن در ۱۹ فصل، از مدل اجرای بلاک‌چین به ساخت یک قرارداد امانی با Solidity، تست با Foundry، استقرار و اتصال TypeScript با Viem می‌رسد. امنیت، توکن‌ها، اوراکل و ارتباط میان زنجیره‌ها هم بررسی می‌شوند.

نشانی نسخهٔ منتشرشده در بخش **Website** مخزن قرار دارد.

## استفاده از راهنما

فایل `index.html` را دانلود و در مرورگر باز کنید. فونت، رنگ‌بندی نحوی و پروژهٔ قابل دانلود داخل همین فایل هستند و برای خواندن راهنما به اینترنت نیاز ندارید. نصب ابزارها و بازکردن منابع به اتصال اینترنت نیاز دارد.

امکانات صفحه شامل جست‌وجوی فصل‌ها، کپی کد، حالت روشن و تیره، چاپ و مدل تعاملی حالت‌های قرارداد است.

برای اجرای یک سرور محلی از ریشهٔ مخزن:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

سپس نشانی <http://127.0.0.1:8080> را باز کنید.

## پروژهٔ نمونه

کد قابل مطالعه در پوشهٔ `examples/escrow-lab` قرار دارد و از داخل راهنما هم قابل دانلود است.

پس از [نصب Foundry](https://getfoundry.sh/introduction/installation/):

```sh
cd examples/escrow-lab
forge install foundry-rs/forge-std@v1.9.7 --no-git
forge build
forge test -vv
```

مبنای بررسی نمونه، نسخه‌های `Solidity 0.8.30`، `Foundry 1.7.1` و `Viem 2.57.7` است. هر ۱۷ تست نمونه، شامل fuzz و invariant، اجرا و تأیید شده‌اند.

قرارداد امانی نمونه، تحویل کالا را تشخیص نمی‌دهد و داوری ندارد. خریدار می‌تواند وجه را آزاد نکند و بعد از مهلت بازپرداخت بگیرد؛ این محدودیت در متن راهنما توضیح داده شده است.

## انتشار

صفحه یک سند HTML مستقل است و به نصب وابستگی یا مرحلهٔ build نیاز ندارد. تنظیمات استقرار در `vercel.json` قرار دارد. پس از اتصال پروژه به Vercel، می‌توانید نسخهٔ تولید را با دستور زیر منتشر کنید:

```sh
vercel --prod
```
